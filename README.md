# Empire City Online

Мобильная игра в открытом мире в духе GTA (Godot 4.3, Android + iOS).

## Что есть в первой версии
- Город 8×8 кварталов: небоскрёбы в центре, жилые дома по краям, парки, фонари, разметка, зебры.
- PBR-освещение, смена дня и ночи (сутки ≈ 20 минут), светящиеся окна ночью, туман, свечение.
- Фотореалистичные текстуры асфальта, бетона и травы с Poly Haven (CC0) — скачиваются при сборке.
- Игрок: ходьба, бег, прыжок, стрельба с автоприцелом, посадка в любую машину (угон).
- 6 машин: седан, спорткар, внедорожник, полиция, такси, фургон. Физика подвески, ручник, урон, взрывы, звук двигателя.
- Трафик ездит по полосам и поворачивает на перекрёстках, пешеходы гуляют и разбегаются при стрельбе.
- Полиция: 5 звёзд розыска, погони с сиреной, копы на ногах стреляют и арестовывают. Чтобы скрыться, уйди из поля зрения.
- Миссии: доставка, угон на заказ, заказное убийство, уличная гонка.
- Деньги, оружейный магазин, автосалон, гараж с купленными машинами, больница. Есть сохранение.
- Онлайн: другие игроки, чат, PvP, сервер на Render.
- Сенсорное управление: джойстик слева, камера свайпом справа, кнопки.

## Сборка
Сделай push в ветку `main`. GitHub Actions соберёт APK и IPA, снимет скриншоты из игры и выложит всё в Releases.

## Сервер онлайна (Render)
New → Blueprint → этот репозиторий (`render.yaml`). Адрес `wss://<имя>.onrender.com` введи в меню игры.

## Свои 3D-модели
Положи `sedan.glb` / `sport.glb` / `suv.glb` / `police.glb` / `taxi.glb` / `van.glb` в папку `models/`, и игра возьмёт их вместо встроенных.
